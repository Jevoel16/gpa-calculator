# Code of conduct

This project is for students, so keep it a place anyone can ask a question without feeling stupid.

- Be kind and patient, especially with first-time contributors.
- Critique code and ideas, not people.
- No harassment, slurs, sexual content or personal attacks, in issues, pull requests or anywhere else tied to the project.
- Don't share anyone's grades, emails or other personal data.

If someone breaks these rules, report it privately through [GitHub security advisories](https://github.com/Jevoel16/gpa-calculator/security/advisories/new) or to [Sprucetrap](https://github.com/Jevoel16). I may edit or remove comments, close threads, or block people who keep doing it.
