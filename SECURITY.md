# Security policy

## Supported versions

Only the latest release and the live site get security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub security advisories](https://github.com/Jevoel16/gpa-calculator/security/advisories/new) with:

- what you found and where (page, endpoint or file),
- steps to reproduce it,
- what an attacker could do with it.

I'll reply within 7 days and tell you when a fix ships. Please give me 30 days before you disclose it publicly.

Test only against your own account or a local copy. Don't read or change other users' data, and don't run load or spam tests against the live site.
